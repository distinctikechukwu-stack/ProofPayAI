# Supabase migrations

Apply migrations in timestamp order. `202610290001_core_project_security.sql` defines the core project/agreement/RLS model. `202610290002_paypal_invoice_workflow.sql` adds accepted-agreement invoice links, provider state and observation timestamps, create/send claim history, and service-role-only authorization/deduplication RPCs. `202610300001_marketplace_profiles.sql` adds self-managed non-admin roles, private client and freelancer profile records, portfolio items, and a restricted projection for opted-in public freelancer profiles. `202610300002_marketplace_jobs.sql` adds jobs, favorites/reports, proposals/events, offers, opt-in services, hiring requests, auth.uid()-derived RPCs, participant RLS, and the sanitized public service view. `202610300003_messaging_notifications.sql` adds project-member conversations, append-only idempotent messages, read receipts, message notifications, block/report controls, participant-scoped private attachments, allowlisted views, and realtime publication for message inserts. `202610300004_hourly_workflows.sql` adds hourly contract versions, a backfill for accepted offers that lack a project, user-controlled timer and timesheet workflows, append-only review/event history, and approved-entry invoice batches that share PayPal's create/send/reconciliation lifecycle. `202610300005_commercial_hardening.sql` adds admin-only job/conversation report queues and decisions, listing holds, append-only moderation audit records, and owner-scoped account deletion requests that do not erase data. The recorded Staging baseline was migrations 1–18 through `202611020004_paypal_webhook_durable_processing.sql`. Migration 19, `202611050001_project_completion_workflow.sql`, was validated locally in isolation and is present in the release candidate; read-only Staging migration history still requires operator confirmation before the next migration. Local migration `202611070001_paypal_provider_snapshot_ordering.sql` is prepared on the Cloudflare webhook branch and has not been applied remotely. Do not place live secrets or real user data in migrations or seed files.

`202611050001_project_completion_workflow.sql` is a local, unapplied migration. It adds participant-triggered completion evaluation for eligible fixed-price agreements, a guarded historical recheck RPC, project workflow serialization, and protection against implicit reopening. It does not backfill existing project statuses or modify invoices/payments. Apply only after separate approval and a fresh Staging preflight.
